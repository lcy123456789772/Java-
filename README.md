# Java Backend Lab

> 见证天才的成长

这是十周 Java 后端基础路线的独立学习仓库，不依赖 Spring Boot。

## 第一次打开

1. 用 IntelliJ IDEA 打开本目录。
2. 等待右侧 Maven 加载完成。
3. 打开 `src/main/java/com/lcy/backendlab/week01/Temperature.java`。
4. 完成两个 `TODO`。
5. 打开 `src/test/java/com/lcy/backendlab/week01/TemperatureTest.java`，点击测试类左侧绿色运行按钮。
6. 测试全部变绿后，再进行第一次 Git 提交。

不要一开始看完整十周计划。今天只完成 `Temperature`。

## 第一次 Git 提交

在项目目录打开 PowerShell：

```powershell
git status
git add .
git commit -m "完成第一道 Java 温度转换题"
```
